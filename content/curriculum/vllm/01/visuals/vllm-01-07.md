### 让五个请求逐个接受 goodput 三门槛判定

actionLabel: "检查下一个请求"

#### 步骤

- 请求 1 | ttft=100 ✓ / tpot=30 ✓ / e2el=3000 ✓ → 计为 goodput。
- 请求 2 | ttft=900 ✗ / tpot=30 ✓ / e2el=3000 ✓ → TTFT 超标，不计。
- 请求 3 | ttft=100 ✓ / tpot=90 ✗ / e2el=3000 ✓ → TPOT 超标，不计。
- 请求 4 | ttft=100 ✓ / tpot=30 ✓ / e2el=26000 ✗ → E2EL 超标，不计。
- 请求 5 | ttft=100 ✓ / tpot=30 ✓ / e2el=3000 ✓ → 计为 goodput。
- 汇总 | 5 个请求中 2 个全达标，goodput = 40%。

#### 观察重点

- 检查到「请求 3」前先预测：如果只声明 ttft:800 而不声明 tpot，请求 3 会被计入 goodput 吗。
- 用课程示例的 goodput_ratio 断言核对 40% 结果，再把阈值改成 ttft:1000 重跑，观察占比变化。
