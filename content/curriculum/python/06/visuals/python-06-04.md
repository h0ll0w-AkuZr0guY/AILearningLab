#### 步骤

- 输入 | Queue.maxsize 让生产者在满时等待，unfinished_tasks 与 join 记录消费确认；关闭要说明剩余项目和生产者责任。 的最小输入和初始状态。
- 模型 | 容量、未完成计数、消费者、生产者和关闭状态组成资源账本；每次 put 至少对应一次 task_done。 中的当前不变量和所有权。
- 主路径 | Queue.put/get 维护队列和计数，join 等待计数归零；Semaphore 只限制令牌，不记录业务完成。 对照源码入口推进一次。
- 失败 | 漏 task_done 永久阻塞，消费者异常不归还令牌，继续无界创建 task 会把背压变成内存增长。 注入失败并记录传播或回滚。
- 边界 | 有界 Queue 传递工作所有权；Semaphore 限制外部资源；shutdown 由生产者拥有者发起。 识别工程和版本取舍。
