#### 步骤

- co_consts 包含字面量、文档… | co_consts 包含字面量、文档字符串以及嵌套函数的 code object。
- co_names 保存由全局、属性和… | co_names 保存由全局、属性和导入相关指令引用的名称。
- co_varnames 以参数开头 | co_varnames 以参数开头，随后是编译器分配的局部名称。
- 行号和异常表把指令偏移映射到源码位置… | 行号和异常表把指令偏移映射到源码位置和异常处理区间，供 traceback 与调试器使用。
