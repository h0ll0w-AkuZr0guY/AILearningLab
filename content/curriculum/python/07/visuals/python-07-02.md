#### 步骤

- 输入 | timeit 默认暂时关闭 GC、重复运行并提供多轮样本；它适合小片段，不等于服务级性能证据。 的最小输入和初始状态。
- 模型 | 基准由问题、样本、环境、统计量和阈值组成；比较只改变一个变量，保留原始向量。 中的当前不变量和所有权。
- 主路径 | Timer.timeit 运行 setup 一次、stmt 多次，repeat 返回多轮结果；pyperf 补充进程、预热和元数据。 对照源码入口推进一次。
- 失败 | 一次 wall-clock、把 setup 算入主体、忽略 GC/CPU 频率、跨版本比较绝对纳秒都会放大噪声。 注入失败并记录传播或回滚。
- 边界 | 快速回归用 timeit，跨机器用 pyperf 和相对基线；报告 Python、CPU、样本和效应量。 识别工程和版本取舍。
