## 大纲审计与优化方向

旧路线把 102 个初轮短文标为 curated，主题覆盖广，却没有把官方锚点、固定源码、运行断言、站内答案和视觉决策落实到每一课；因此它们不能继续代表完成度。新的路线以 Python 语言合同、CPython 运行时与工程诊断三条线交叉组织，压缩为 41 个可独立验证的最终课题。

| 模块 | 最终课数 | 重构动作 |
| --- | ---: | --- |
| 01 对象、身份与序列 | 5 | 合并对象布局、引用生命周期与集合布局；保留五个相互独立的失败模型。 |
| 02 属性、描述符与继承 | 5 | 把零散的字典、descriptor、绑定与 MRO 收敛成一条属性解析链。 |
| 03 函数、作用域与生成器 | 5 | 合并 code/frame 细节与闭包、参数、装饰器；保留生成器状态机与委派。 |
| 04 异常、资源与异步协议 | 5 | 合并异常链、上下文管理与 coroutine/async iterator 的清理边界。 |
| 05 导入、类型与发布 | 5 | 合并 import pipeline、包环境、注解与静态 API 契约。 |
| 06 asyncio 与并发控制 | 5 | 围绕调度、取消、结构化并发、背压和线程/进程边界组织。 |
| 07 性能、内存与诊断 | 5 | 只保留数据结构选择、基准、CPU/内存剖析、解释器与并行证据。 |
| 08 CPython 执行链与扩展 | 6 | 把前端、编译、执行、调用、特化和源码改造串成一个端到端产出。 |

**终极产出**：读者可以实现一个带属性协议、调用绑定、生成器式暂停、导入缓存和可观测执行轨迹的 mini Python runtime，并使用固定版本的 CPython 源码和实验解释差异。
