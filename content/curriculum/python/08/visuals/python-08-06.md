#### 步骤

- 输入 | 可回退的 CPython 改动必须同时经过公开入口、内部状态、测试和兼容说明；审计钩子是新增观测而不改变结果的例子。 的最小输入和初始状态。
- 模型 | 改造分行为契约、实现入口、观测证据、回归测试、发布说明五层；默认行为不变，新增观测可忽略。 中的当前不变量和所有权。
- 主路径 | sys_addaudithook 注册解释器级 hook，事件在关键操作点触发；Lib/test 和 C API 测试验证参数、顺序和异常边界。 对照源码入口推进一次。
- 失败 | hook 中重入、把事件参数当永久 schema、只跑 happy path、忽略子解释器/free-threaded，会制造新故障。 注入失败并记录传播或回滚。
- 边界 | 先写 Python 回归，再固定 C 入口和测试命令；新增 API 先写公开兼容策略，不暴露 internal headers。 识别工程和版本取舍。
